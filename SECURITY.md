## 🛡️ Reporting a Vulnerability

If you discover a security vulnerability within Power Gym, please send an email to the development team instead of opening a public issue.

- **Developer:** Sayed Khashana
- **Contact Phone / WhatsApp:** `+20 1559666564`

Please include:
1. Description of the vulnerability.
2. Steps to reproduce or proof-of-concept.
3. Potential impact.

We will acknowledge receipt within 48 hours and work on a fix promptly.
